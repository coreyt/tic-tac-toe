# Feature Backlog

These items are ideas for future work; they are not yet implemented or committed requirements.

- [ ] **SQLite leaderboard:** Store leaderboard entries in a SQLite database instead of `leaderboard.csv`.
- [ ] **Player accounts and records:** Allow players to log in with a username and password, store account information in SQLite, and track each player's wins and losses.
- [ ] **Network play:** Allow two players to connect over TCP/IP using port 9090, including when both players are on the same machine.
- [ ] **Player colors:** Let players choose a color when they play.
- [ ] **Godzilla Easter egg:** When a user types `godzilla`, show an ASCII monster walking across the board and wrecking it.
